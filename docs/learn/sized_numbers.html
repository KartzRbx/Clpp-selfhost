Sized Numbers

❮ PreviousNext ❯

number and float use 64 bits, which is enough for almost everything. Sized numbers let you choose exactly how big a number can be. They describe data precisely (a color channel is 0 to 255) and let the computer store large amounts of numbers in less memory.

Whole numbers with a sign: i8, i16, i32, i64

i means integer: positive, negative or zero. The number is the size in bits.

TypeBitsSmallestLargestGood for
i88-128127small offsets, tiny counters
i1616-32 76832 767tile coordinates, audio samples
i3232-2 147 483 6482 147 483 647counters, scores, most whole numbers
i6464-9 223 372 036 854 775 8089 223 372 036 854 775 807timestamps, ids; same as number

Whole numbers without a sign: u8, u16, u32, u64

u means unsigned: zero or positive. The same number of bits reaches twice as high.

TypeBitsSmallestLargestGood for
u880255bytes, RGBA color channels
u1616065 535ports, small ids
u323204 294 967 295entity ids, sizes, bit masks
u646409 223 372 036 854 775 807 (for now)large ids

Floating point: f16, f32, f64

Floats hold decimals using the IEEE 754 standard. Fewer bits mean fewer correct digits.

TypeBitsCorrect digitsLargestGood for
f1616about 365 504colors, weights, data sent over the network
f3232about 7about 3.4 × 10³⁸positions, physics, graphics
f6464about 15 to 17about 1.8 × 10³⁰⁸money, science; same as float

Declaring sized numbers

Example

u8 red = 255
u8 green = 128
i16 offsetX = -300
u32 entityId = 4000000000
f32 speed = 7.5
f16 alpha = 0.5
post(`color ${red}, ${green}`)
post(`offset ${offsetX}, id ${entityId}`)
post(`speed ${speed}, alpha ${alpha}`)
Output
color 255, 128
offset -300, id 4000000000
speed 7.5, alpha 0.5

Rule 1: a literal must fit

A number written directly in the code (a literal) must fit in the type. Otherwise it is an error, found before the program runs.

Example with an error

u8 tooBig = 300
Error
error: 300 does not fit in u8 (range 0 .. 255)
help: use a wider type such as i32, i64 or f64

Example with an error

u16 negative = -1
Error
error: -1 does not fit in u16 (range 0 .. 65535)
help: use a wider type such as i32, i64 or f64

Rule 2: computed values wrap around

When a calculation stored in a sized variable goes past the limit, it wraps around, exactly like the CPU does: after the largest value comes the smallest one. This is called overflow.

Example

u8 counter = 250
counter += 10
post(counter)

i8 small = 127
small += 1
post(small)

u8 down = 3
down -= 5
post(down)
Output
4
-128
254

Why 4? 250 + 10 is 260, and a u8 only counts to 255: 260 - 256 = 4. Why 254? 3 - 5 is -2, which wraps to 256 - 2.

Tip: Wrapping is useful for hashes, random number generators and angles in steps. If it would be a bug, use a bigger type or check the value first.

Rule 3: whole numbers become floats, never the opposite

A whole number can be stored in any float type. A decimal cannot be stored in a whole-number type: you must decide how to round it with Math.floor, Math.round or Math.trunc.

Example

link @clpp.math as Math

f32 ratio = 3
post(ratio)
float measured = 2.7
i32 rounded = Math.round(measured)
post(rounded)
Output
3.0
3

Example with an error

i32 rounded = 2.7
Error
error: i32 needs a whole number, got 2.7 (convert with Math.floor, Math.round or Math.trunc)
help: use a whole number, or a float type: (f32 2.7)
error: 'rounded': expected i32, got float
help: use Math.floor, Math.round or Math.trunc, or declare a float

Precision of floats

0.1 cannot be stored exactly in binary. The fewer bits, the further away the stored value is.

Example

f16 half = 0.1
f32 single = 0.1
f64 double = 0.1
post(half)
post(single)
post(double)
Output
0.0999755859375
0.10000000149011612
0.1

Example

f16 big = 2049
post(big)
f16 limit = 65504
post(limit)
Output
2048.0
65504.0

2049 became 2048: above 2048, an f16 can only hold even numbers. Keep f16 for values that do not need many digits.

Mixing sizes

Arithmetic is done with full 64-bit numbers. The result is converted only when it is stored in a sized variable or field.

Example

u8 a = 200
u8 b = 100
number sum = a + b
u8 wrapped = a + b
post(sum)
post(wrapped)
Output
300
44

Sized fields

Fields of a def follow the same rules every time they change.

Example

def Pixel {
    u8 Red
    u8 Green
    u8 Blue
    f16 Alpha = 1.0
}

Pixel p = Pixel { Red = 250, Green = 10, Blue = 0 }
p.Red += 10
post(`${p.Red} ${p.Green} ${p.Blue} ${p.Alpha}`)
Output
4 10 0 1.0

Choosing an exact type with (Type value)

Example

post((u16 65535))
post((f16 0.333))
post((i8 -128))
Output
65535
0.3330078125
-128
